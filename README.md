# Petroleum Intelligence Map

Static GitHub Pages site for the Petroleum Exploration and Development Intelligence Opportunity Map. It includes the 13-stage site framework and five mud-logging case demonstrations (m1-m5).

## Publish with GitHub Pages

Configure repository Settings → Pages → Deploy from a branch → `main` / `/(root)`. The entry point is `index.html`.

All demo curves, images, and report fields are synthetic teaching examples; they do not represent real wellsite data or validated model performance.
